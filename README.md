# 💰 Мой бюджет — Умный учёт финансов (v2.3)

Простое, но мощное веб-приложение (PWA) для контроля ежемесячного бюджета, оптимизированное для учёта любого регулярного дохода: пенсии, зарплаты или стипендии.

## 📖 Описание

Приложение помогает рассчитать, сколько можно безопасно тратить каждый день, учитывая:
- Размер ежемесячного дохода и день его получения
- Неприкосновенный запас (резерв)
- Обязательные ежемесячные платежи (ЖКХ, кредиты, подписки)
- **Баланс по нескольким счетам** с умной логикой контроля

## ✨ Ключевые возможности

### 🚀 Улучшения интерфейса и надёжности (v2.3)
- **Прозрачная детализация:** на вкладке «Обзор» при просмотре категории фиксированные и обычные платежи показываются раздельно. Сумма «Итого» считается честно, только по выбранной группе.
- **Улучшенный UX вкладки «Анализ»:** категории по умолчанию свёрнуты, суммы строго выровнены по правому краю, а на мобильных устройствах долгое нажатие на подкатегорию показывает её процент от родительской категории.
- **Надёжный парсинг данных:** исправлена обработка чисел в настройках. Ввод значений с пробелами и запятыми (например, `34 714,73`) теперь обрабатывается корректно и не приводит к ошибкам расчёта.
- **Чистота аналитики:** скрыты фантомные записи товаров с нулевой суммой и пустым именем, которые могли возникать при миграции старых данных.

### 📊 Финансовый контроль
- **Главный экран**: показывает точный дневной лимит с цветовой индикацией статуса (зелёный/жёлтый/красный).
- **История операций**: группировка по дням с разделением доходов и расходов.
- **Цветные индикаторы подкатегорий**: визуальные кружки для мгновенного распознавания трат в списке.

### 🔍 Расширенный контроль истории (v2.2)
- **Мгновенный поиск**: фильтрация записей по категории, предмету, месту или комментарию.
- **Архивация транзакций**: возможность скрыть отдельные записи или целые периоды без удаления (с функцией массового и индивидуального восстановления).
- **Гибкие фильтры**: просмотр истории за день, неделю, месяц или любой произвольный период через встроенный календарь.
- **Фильтр по счетам**: изоляция операций конкретного банка или наличных в общем списке.

### 📈 Продвинутая аналитика и статистика (v2.2)
- **Drill-down (детализация)**: клик по категории в статистике открывает список конкретных транзакций за выбранный период с итоговой суммой.
- **Синхронизация периодов**: экран статистики автоматически подхватывает даты, выбранные в фильтре истории операций.
- **Точный учёт доходов**: корректный расчёт пенсий/зарплат при просмотре длинных периодов (автоматический подсчёт количества поступлений в выбранном диапазоне).

### 💳 Многоконточность и умная логика счетов (v2.1)
- Поддержка неограниченного количества счетов (Сбербанк, Тинькофф, Наличные и др.).
- **Защита от перерасхода**: Приложение автоматически проверяет баланс всех счетов и блокирует расход, если средств недостаточно.
- **Накопительные счета**: исключены из формы обычного расхода (пополняются только через трансфер), чтобы защитить ваши сбережения от случайных трат.
- Переводы между собственными счетами без искажения общей статистики.

### 📦 Архивация и перенос остатка
- Закрытие периода одним кликом с созданием полного исторического снапшота.
- Автоматический расчёт и перенос нераспределённого остатка в новый период.
- Просмотр детальной истории и итогов закрытых периодов.

### ⚙️ Удобство и надёжность
- 🌙 **Тёмная тема**: бережёт глаза при вечернем учёте.
- 📱 **PWA (Progressive Web App)**: установка на смартфон и работа в офлайн-режиме.
- 💾 **Экспорт/Импорт**: полное резервное копирование данных в JSON.
- 📱 **Адаптивная вёрстка**: корректное отображение статистики и процентов на экранах любых смартфонов.
- 📅 **Умный перенос дат**: автоматическая корректировка фиксированных платежей с 29-31 числа на последний день месяца (например, на 28 февраля), чтобы платежи не "пропадали".

## 🛠 Технологии

- **HTML5 / CSS3**: CSS-переменные, Grid/Flexbox, адаптивная вёрстка.
- **JavaScript (ES6+)**: Модульная архитектура (`import`/`export`), работа с `localStorage`.
- **Chart.js**: Визуализация структуры расходов в виде круговой диаграммы.
- **GitHub Pages**: Бесплатный и надёжный хостинг.

## 📱 Как начать использовать

1. Откройте приложение: [https://mihail5719.github.io/pension-budget/](https://mihail5719.github.io/pension-budget/)
2. При первом запуске пройдите **Приветственный экран**.
3. Перейдите в раздел **«Настройки»**:
   - Укажите размер дохода и день его получения.
   - В поле «Источник дохода» выберите тип (Пенсия, Зарплата и т.д.).
   - Задайте сумму неприкосновенного запаса (НЗ).
   - Добавьте свои счета (приложение само подставит цвета банков).
   - Внесите обязательные ежемесячные платежи.
4. На главном экране нажмите **«✅ Отметить поступление»**, чтобы начать период.
5. Используйте кнопки **«+ Расход»** или **«+ Доход»** для ведения учёта.
