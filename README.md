#  Мой бюджет — Приложение для учёта пенсии

Простое и удобное веб-приложение для контроля ежемесячного бюджета пенсионера.

## 📖 Описание

Приложение помогает рассчитать, сколько можно безопасно тратить каждый день, учитывая:
- Размер ежемесячной пенсии
- День получения пенсии
- Неприкосновенный запас (резерв)
- Обязательные ежемесячные платежи (ЖКХ, кредиты, интернет и т.д.)

## ✨ Возможности

- 📊 **Главный экран** — показывает сумму, которую можно потратить сегодня
- 📝 **История операций** — все доходы и расходы в одном месте
- ⚙️ **Настройки** — гибкая конфигурация под ваши нужды
- 🌙 **Тёмная тема** — переключение между светлой и тёмной темой
-  **Экспорт/Импорт** — резервное копирование данных в JSON
- 📱 **Адаптивный дизайн** — работает на компьютерах и смартфонах
- 👋 **Приветственный экран** — помогает новым пользователям начать работу

##  Технологии

- HTML5
- CSS3 (градиенты, CSS-переменные, адаптивная вёрстка)
- JavaScript (ES6+, localStorage)
- GitHub Pages (хостинг)

## 📱 Как использовать

1. Откройте приложение: [https://mihail5719.github.io/pension-budget/](https://mihail5719.github.io/pension-budget/)
2. Перейдите в раздел **«Настройки»**
3. Укажите размер пенсии, день получения и неприкосновенный запас
4. Добавьте обязательные платежи
5. Вернитесь на главный экран — приложение покажет, сколько можно потратить сегодня
