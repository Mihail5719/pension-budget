# 💰 Мой бюджет — Умный учёт финансов (v2.1)

Простое, но мощное веб-приложение (PWA) для контроля ежемесячного бюджета, оптимизированное для учёта пенсии, стипендии или зарплаты.

## 📖 Описание

Приложение помогает рассчитать, сколько можно безопасно тратить каждый день, учитывая:
- Размер ежемесячного дохода и день его получения
- Неприкосновенный запас (резерв)
- Обязательные ежемесячные платежи (ЖКХ, кредиты, подписки)
- **Баланс по нескольким счетам** (новая функция v2.1)

## ✨ Ключевые возможности

### 📊 Финансовый контроль
- **Главный экран**: показывает точный дневной лимит с цветовой индикацией статуса (зелёный/жёлтый/красный).
- **История операций**: группировка по дням с разделением доходов и расходов.
- **Цветные индикаторы подкатегорий**: визуальные кружки (🔴 Мясо, 🟢 Овощи, 🔵 Молочное) для мгновенного распознавания трат в списке и при вводе.

### 💳 Многоконточность (v2.1)
- Поддержка неограниченного количества счетов (Сбербанк, Тинькофф, Наличные и др.).
- **Умные цвета банков**: автоматическое определение иконок и цветов для популярных банков.
- Переводы между собственными счетами без искажения общей статистики.

### 📦 Архивация и перенос остатка (v2.1)
- Закрытие периода одним кликом с созданием полного исторического снапшота.
- Автоматический расчёт и перенос нераспределённого остатка в новый период.
- Просмотр детальной истории и итогов закрытых периодов.

### ⚙️ Удобство и надёжность
- 🌙 **Тёмная тема**: бережёт глаза при вечернем учёте.
- 📱 **PWA (Progressive Web App)**: установка на смартфон и работа в офлайн-режиме.
- 💾 **Экспорт/Импорт**: полное резервное копирование данных в JSON.
- 🔄 **Автоматическая миграция**: безопасное обновление старых данных до новой версии.

## 🛠 Технологии

- **HTML5 / CSS3**: CSS-переменные, Grid/Flexbox, адаптивная вёрстка.
- **JavaScript (ES6+)**: Модульная архитектура (`import`/`export`), работа с `localStorage`.
- **Chart.js**: Визуализация структуры расходов в виде круговой диаграммы.
- **GitHub Pages**: Бесплатный и надёжный хостинг.

## 📱 Как начать использовать

1. Откройте приложение: [https://mihail5719.github.io/pension-budget/](https://mihail5719.github.io/pension-budget/)
2. При первом запуске пройдите **Приветственный экран**.
3. Перейдите в раздел **«Настройки»**:
   - Укажите размер дохода и день его получения.
   - Задайте сумму неприкосновенного запаса (НЗ).
   - Добавьте свои счета (приложение само подставит цвета банков).
   - Внесите обязательные ежемесячные платежи.
4. На главном экране нажмите **«✅ Поступление: Пенсия»**, чтобы начать период.
5. Используйте кнопки **«+ Расход»** или **«+ Доход»** для ведения учёта.
