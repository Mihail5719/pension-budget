## 🚦 Индикатор безопасного дневного лимита

### Смысл

Индикатор — это **светофор** бюджета. Одним взглядом на цвет видна ситуация:

- 🟢 **Зелёный (`ok`)** — всё хорошо, тратьте спокойно
- 🟠 **Оранжевый (`warn`)** — внимание, денег в день выходит мало
- 🔴 **Красный (`danger`)** — тревога, свободных денег нет или минус

### Устройство: конвейер из 4 деталей

```
РАСЧЁТ (budget.js)  →  РЕШЕНИЕ (ui.js)  →  ПРИМЕНЕНИЕ (ui.js)  →  ОКРАСКА (style.css)
calculateDailyLimit    getIndicatorState    renderTodayScreen     .indicator--ok/warn/danger
числа                  вердикт-слово        вешает класс          класс даёт цвет
```

1. **Расчёт** (`js/budget.js`, `calculateDailyLimit`) — считает числа:
   - `freeBudget` = текущий баланс − НЗ − обязательные платежи
   - `dailyLimit` = freeBudget / дней до пенсии
2. **Решение** (`js/ui.js`, `getIndicatorState`) — возвращает слово: `ok` / `warn` / `danger`
3. **Применение** (`js/ui.js`, `renderTodayScreen`) — вешает класс на кружок:
   `indicatorEl.classList.add('indicator--' + indicatorState)`
4. **Окраска** (`css/style.css`) — каждому классу свой цвет через переменную:
   - `.indicator--ok` → `var(--color-ok)` (зелёный)
   - `.indicator--warn` → `var(--color-warn)` (оранжевый)
   - `.indicator--danger` → `var(--color-danger)` (красный)

### Логика вердикта (функция getIndicatorState)

```javascript
if (freeBudget <= 0) return 'danger';        // денег нет вообще
const ratio = dailyLimit / (freeBudget / 30);
if (dailyLimit < 0) return 'danger';         // лимит в минусе
if (ratio < 0.5) return 'warn';              // лимит вдвое ниже идеала
return 'ok';                                 // иначе всё хорошо
```

### Секретная математика

`ratio = 30 / днейОсталось` — зависит **только от дней до пенсии**, не от суммы!

| Дней до пенсии | ratio | Вердикт |
|----------------|-------|---------|
| 30 | 1.0 | 🟢 ok |
| 28 | 1.07 | 🟢 ok |
| 60 | 0.5 | 🟢 ok (граница) |
| 61+ | <0.5 | 🟠 warn |

**На практике:**
- 🟢 Зелёный — обычный режим (до пенсии <60 дней, деньги есть)
- 🟠 Оранжевый — пенсия задержалась больше чем на 2 месяца
- 🔴 Красный — свободные деньги кончились или минус

### Сквозной пример

Дано: freeBudget = 27289, дней = 28, dailyLimit = 974.61
1. freeBudget <= 0? Нет
2. ratio = 30/28 = 1.07
3. dailyLimit < 0? Нет
4. ratio < 0.5? Нет
5. Вердикт: **ok** → зелёный ✅

### Где что лежит (шпаргалка)

| Что | Где |
|-----|-----|
| Кружок (HTML) | `index.html`: `<div id="indicator">` |
| Расчёт чисел | `js/budget.js`: `calculateDailyLimit` |
| Вердикт | `js/ui.js`: `getIndicatorState` |
| Вешание класса | `js/ui.js`: `renderTodayScreen` |
| Цвета классов | `css/style.css`: `.indicator--ok/warn/danger` |
| Значения цветов | `css/style.css`: `:root` и `body.dark-theme` |

### Быстрая проверка в консоли (F12)

```javascript
document.getElementById('indicator').className
```
Покажет текущий вердикт, например `today-card__indicator indicator--ok`.

### Развеянные заблуждения

1. ❌ Цвет от потраченного сегодня → ✅ от дней до пенсии и знака freeBudget
2. ❌ Зелёный = базовый цвет кружка → ✅ зелёный даёт класс `indicator--ok`
3. ❌ Переменных `--color-ok/warn` нет → ✅ они есть в `:root`

## 📐 Основные формулы приложения

- **Текущий баланс:** `initialBalance + pension + income − spent`
- **Свободный бюджет:** `currentBalance − reserveAmount − fixedTotal`
- **Дневной лимит:** `freeBudget / daysLeft`
- **Перенос остатка:** `новый initialBalance = currentBalance − fixedTotal`
  (НЗ НЕ вычитается — он переносится внутри остатка)

---

## 📝 Правила учёта

- Обязательные платежи (ЖКХ, Связь) учитываются **планово** через `fixedTotal`.
  Их **НЕ** записывают как обычные расходы (иначе двойное вычитание).
- НЗ (`reserveAmount`) — **неприкосновенный** запас (Модель А): константа-настройка,
  не растёт автоматически. Накопления — вручную через категорию расходов.

---

## 🔓 Использование НЗ (аварийный режим)

- Кнопка видна только при НЗ > 0
- Снятие создаёт транзакцию type='reserve'
- reserveAmount уменьшается на сумму снятия
- Дневной лимит при этом НЕ меняется
- Удаление записи возвращает сумму в НЗ
- Карандашик (правка) для записей НЗ скрыт
- Записи НЗ помечены оранжевой полосой

## 🗂 Подкатегории расходов

- Таблица SUBCATEGORIES: у каждой категории 3-5 подкатегорий
- Выбор подкатегории обязателен (заглушка + проверка)
- Каскад: смена категории пересоздаёт список подкатегорий
- В транзакции поле subcategory хранит название
- История показывает подкатегорию второй серой строкой
- При редактировании подкатегория меняется с категорией

### Короткие имена и мобильная адаптация

- Категории: "Аптека", "Транспорт", "Здоровье" (без вторых слов)
- Подкатегория: "Наличные" (вместо "Наличные в копилку")
- Миграция один раз переименовывает старые записи на каждом устройстве
- История на мобильных: две строки (инфо сверху, сумма и кнопки снизу)
- Шрифт подкатегорий 13px на всех устройствах
- Заглушка в селекте: "-- выберите --" (помещается на узком экране)
- Плашка НЗ на десктопе: по центру, ширина как у карточки
