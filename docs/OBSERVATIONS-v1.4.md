# Наблюдения тестового периода v1.4

Период: 20.09.2026 — 04.10.2026 (две недели реальной эксплуатации)
Цель: собрать материал для проектирования v2.0 (PWA, рефакторинг, руководство)

---

## 20.09.2026

### Наблюдение 1: Расхождение баз при правках на одном устройстве
- **Ситуация:** отредактировал категорию записи (880 ₽, 30.08) только
  на смартфоне. Десктоп не узнал — в статистике категории разошлись
  (Продукты vs Другое).
- **Причина:** три независимых localStorage (верстак, стенд, смартфон),
  ручная синхронизация через экспорт/импорт легко пропускается.
- **Временное правило:** смартфон = мастер-устройство. Десктоп = просмотр.
  После пачки правок — экспорт→Telegram→импорт в тот же день.
- **Идея для v2.0:** индикатор синхронизации в Настройках:
  счётчик записей + дата последнего экспорта. Расхождение видно сразу,
  а не через статистику.

### Наблюдение 2: Надпись "Нет расходов за этот период" на мобильном
- **Ситуация:** после очистки периода надпись на смартфоне выходила
  за правую границу карточки.
- **Причина:** текст рисовался на canvas — на плотных экранах
  внутренняя сетка пикселей рассинхронизировалась с размером элемента.
- **Исправлено:** надпись перенесена в DOM (HTML-элемент), центрируется
  через CSS-отступы. Коммит в v1.4-test.

### Наблюдение 3: Кнопка сброса/изменения периода слишком доступна
- **Ситуация:** на узком экране смартфона легко нажать случайно.
- **Идея для v2.0:** добавить подтверждение перед сбросом периода
  ("Вы уверены? История текущего периода сохранится в истории, но
  статистика пересчитается").

### Наблюдение 4: Три независимых "склада" данных
- **Ситуация:** верстак (127.0.0.1), стенд (github.io на десктопе) и
  смартфон — три разные базы в одном проекте. Глазом не отличить,
  нужна сверка.
- **Инструмент диагностики:** экспорт с каждого склада + сравнение
  через VS Code Compare (ПКМ → Select for Compare). Различия видны
  сразу, без поиска глазами.
- **Идея для v2.0:** единая база (например, через Backend/API) или
  хотя бы явный индикатор "на этом устройстве N записей, последний
  импорт M дней назад".

### Рабочее правило (принято 20.09.2026):
> Правки категорий и записей делаем ТОЛЬКО на смартфоне (мастер).
> Десктоп — просмотр + импорт после пачки правок.
> Верстак (127.0.0.1) — лаборатория для тестов, не синхронизируем.
