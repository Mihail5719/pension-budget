# Changelog

Все значимые изменения в проекте "Мой бюджет" будут документироваться в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

## [2.1.0] - 2026-10-31

### 🎉 Новые возможности
- **Умный баннер для новичков**: приложение автоматически определяет вход в середине периода (после дня получения дохода) и показывает подсказку с инструкцией.
- **Пошаговая инструкция**: модальное окно с 4 шагами настройки для новых пользователей (универсальный текст для любого типа дохода: пенсия, зарплата, стипендия).
- **Счёт "Наличные"**: выделен в отдельную логику, доступен для доходов и расходов.
- **Накопительные счета**: исключены из формы расхода (только через трансфер), удалена категория "Накопления" из расходов.
- **Защита от перерасхода наличных**: приложение блокирует расход, если на счёте "Наличные" недостаточно средств (банковские счета не проверяются — банк контролирует сам).

### 🐛 Исправления
- Исправлено отображение начального остатка в настройках (убраны артефакты floating point: `25656.010000000002` → `25656.01`).
- Исправлено ложное срабатывание "Недостаточно средств" для банковских счетов.
- Исправлено сравнение дат при расчёте баланса (корректная работа с объектами `Date`).
- Устранён артефакт `) -->` в HTML (конфликт комментария с live-server).

### 📱 Улучшения UX/UI
- Адаптивная вёрстка статистики: проценты больше не вылезают за границу экрана на мобильных устройствах.
- Добавлена кнопка "Как настроить?" в баннере середины периода.
- Универсальный текст вместо узкого "пенсия" → "регулярный ежемесячный доход".

### 🔧 Технические изменения
- Динамический расчёт баланса счёта: `initialBalance` + транзакции текущего периода.
- Фильтрация транзакций по `currentPeriodStart` для корректного расчёта.
- Поле "Начальный остаток" в настройках сделано только для чтения (рассчитывается автоматически).

## [2.1.0] - 2026-10-24

### 🐛 Исправления
- **Критическое исправление логики смены периода:** Кнопка "Изменить" дату поступления пенсии теперь автоматически и корректно пересчитывает начальные балансы всех счетов при переходе в новый период.
- Функция расчёта баланса теперь честно учитывает все транзакции (включая операции самого дня смены периода до 23:59:59), что предотвращает потерю данных или появление отрицательных балансов при ручном изменении даты.
- Устранена рассинхронизация между глобальным начальным остатком и балансами отдельных счетов.

### ✅ Тестирование
- Логика протестирована на локальном сервере и на реальном устройстве (смартфон).
- Балансы счетов успешно сверены с реальными данными банковских приложений.
